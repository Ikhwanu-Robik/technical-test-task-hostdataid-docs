## The Flow

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant App
    actor Tester
    participant Callback
    participant DB as [Database] callback_logs

    Note over User,App: Phase 1: Order Creation
    User->>App: Send create order request
    
    alt is valid JSON?
        App->>App: Validate JSON inputs
        alt inputs are valid?
            App->>App: Check rate limit (10s window)
            alt not a duplicate?
                App->>App: Create Order
                App-->>User: Return order details
            else is duplicate
                App-->>User: Error: Duplicate request
            end
        else invalid inputs
            App-->>User: Error: Invalid fields
        end
    else invalid JSON
        App-->>User: Error: Bad Request format
    end

    Note over Tester,Callback: Phase 2: Callback Trigger
    Tester->>App: Call callback trigger (ref_id, status)
    
    App->>App: Check status is valid
    App->>App: Check order exists (ref_id)
    
    App->>Callback: Send request to callback
    
    Callback->>Callback: Check status is valid
    Callback->>Callback: Check order exists (ref_id)
    
    Callback->>Callback: Update order status
    Callback->>DB: Save request to callback_logs
    Callback-->>App: Return success message
```

## 10 Seconds Anti-Duplicate-Request

When a user sends a request to create order, the app check the
**orders** table in the database to see if there's any record with
the same **reference_id** in the last 10 seconds. If there's any, the 
app will return a 409 HTTP response.
